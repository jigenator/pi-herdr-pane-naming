# pi-herdr-pane-naming

A planned Pi extension to keep Herdr pane names aligned with the current task,
without agents repeatedly constructing shell commands to rename panes.

## Status

Repository bootstrap only. No extension has been implemented.

## Possible direction

Use Jev to detect when work becomes a new task and trigger pane naming, rather
than spend the main agent's tokens on that housekeeping. The integration and
naming mechanism are not yet decided.
